Multiplication Challenge
========================

Live website:
https://rentosaijo.github.io/COM440/projects/project2/

Open locally:
Extract the entire ZIP file, then double-click index.html. Keep styles.css and script.js in the same folder as index.html. No internet connection or local server is needed.

Choose a table size from 1 to 20, then fill in the missing product before the countdown ends. Press Enter or select Check Answer to submit early.
